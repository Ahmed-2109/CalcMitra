# 🧮 CalcMitra – Online Calculator

CalcMitra is a modern, responsive, and interactive online calculator built using HTML, CSS, and JavaScript.  
It performs essential arithmetic operations such as addition, subtraction, multiplication, and division with a premium glassmorphism user interface, smooth animations, theme customization, and calculation history support.

Designed with a futuristic UI and responsive layout, this project delivers a clean and engaging user experience across desktop and mobile devices.

---

# ✨ Features

## 🔢 Basic Arithmetic Operations
- Addition
- Subtraction
- Multiplication
- Division

## 🎨 Modern UI Design
- Premium Glassmorphism Interface
- Smooth Hover & Click Animations
- Floating Background Orbs
- Particle Animation Effects

## 📋 Extra Functionalities

- Calculation History
